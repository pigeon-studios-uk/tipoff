# Tipoff brand

Tipoff's logo, icons and banners. `source/` has the SVGs, drawn from geometry, and `exports/` the PNGs made from them. Use them only as [NOTICE.md](../../NOTICE.md) says: with a copy of Tipoff, and never to suggest your copy is the official Tipoff or run by Pigeon Studios.

## The mark

A slanted **T** with an orange **speech bubble** cut out of its top-right, holding an **!**. Every slanted edge shares one slope (0.6 across per 1 down, about 31°). The gap between the T and the bubble, and the "!", are cut out with masks, so the mark works on any background, including transparent.

| | |
|---|---|
| Orange | `#FF6200` |
| Ink (background) | `#0F1015` |
| Ink, lighter (banner depth) | `#171A21` |
| White | `#FFFFFF` |
| Wordmark | Archivo ExtraBold, 125% width (SIL Open Font Licence), turned into outlines: "Tip" in white (ink on light backgrounds), "off" in orange |
